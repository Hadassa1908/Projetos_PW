Alguns códigops que aprendi...

Todos foram feitos no Visual Studio Code

Os códigos apresentados são de HTML e CSS para criar e estilizar uma página da web. Eles definem o plano de fundo com uma imagem, configuram um título centralizado, um menu de navegação horizontal com efeitos ao passar o mouse (hover), um rodapé com cor de fundo e texto centralizado, além de utilizar media queries para tornar a página responsiva, adaptando o layout para telas menores, como tablets e celulares. Dessa forma, o site fica mais organizado, bonito e acessível em diferentes dispositivos.
